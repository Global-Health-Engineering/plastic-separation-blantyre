README for `./hardware`

The hardware directory contains two sub-directories: `design` and `testing`.

# `hardware/design`

This directory contains the design files for the developed prototype. It includes 3D part files, technical drawings, and others to reproduce the designs.
For further information see the `README.md` file in the `./hardware/design` directory.

# `hardware/testing`

In this directory, detailed documentation including testing description, schedule, tools, results, and evaluation are provided in this directory.
For further information see the `README.md` file in the `./hardware/testing` directory.

---
README for `./media`
---

In the `./media` directory, photos and videos concerning the project are stored.
It is divided into three sub-directories: `design`, `manufacturing`, and `testing`.

**Note:** Not all media files (especially videos) are available on GitHub. Request access to supplementary material from the author.

# `media/design`

This directory contains screenshots of the prototype unit representations in the CAD software Siemens NX 1988.
The underlying part files are available in the `./hardware/design` directory.

Furthermore, the projected workflow of the washing and separation process is visualized in a video.

# `media/manufacturing`

Here, the fabrication process and milestones of the prototype manufacturing are documented.

# `media/testing`

In this directory, the media recorded during the tests is provided.
It is sorted into one folder for each conducted test and named correspondingly.
For detailed information on the different tests, see the `README.md` file in the `./hardware/testing` directory.
